# 🎓 Veritas English (베리타스 잉글리시)
> **영재학교 아카데믹 스타일의 지능형 스마트 영어 학습 플랫폼**

초등학생부터 수험생, 성인까지 누구나 쉽고 효과적으로 영어를 체화할 수 있도록 설계된 지능형 웹 애플리케이션입니다.

---

## 🌟 주요 핵심 기능

### 1. 📸 교재 사진 캡처 OCR 단어 자동 등록
- 보유하고 계신 단어장, 교재, 시험지 사진을 업로드하거나 화면 캡처 후 `Ctrl + V`로 바로 붙여넣기.
- **Tesseract.js** 기반의 영한 OCR 엔진이 영단어, 품사(`n.`, `v.`, `a.`), 한글 의미를 자동 분석.
- 오타나 불필요한 단어를 직접 교정하고, 학습 계획 일자(`YYYY-MM-DD`) 및 태그를 지정하여 플래너에 일괄 등록.
- *"샘플 교재 이미지로 즉시 체험"* 버튼으로 교재 사진이 없어도 즉시 테스트 가능.

### 2. 🎴 3D 플립 플래시카드 & 원어민 발음 (TTS)
- 매끄러운 3D 카드 회전 애니메이션 (앞면: 영단어/품사/원어민 음성, 뒷면: 의미/실전 예문).
- **키보드 단축키 지원**:
  - `Space`: 카드 뒤집기
  - `1` 또는 `←`: 몰라요 (Hard) - 내일 다시 복습 (1단계 강등)
  - `2` 또는 `↓`: 애매해요 (Good) - 현단계 유지
  - `3` 또는 `→`: 알아요 (Easy) - 다음 단계 승급
  - `P`: 원어민 발음 듣기
- Web Speech API 기반 고품질 미국식(`en-US`) / 영국식(`en-GB`) 발음 및 재생 속도 조절 지원.

### 3. 🧠 4종 지능형 스마트 퀴즈
1. **객관식 4지선다 퀴즈**: 영단어를 보고 4개의 한글 보기 중 정답 선택 (키보드 1~4번 단축키 지원).
2. **스펠링 타이핑 챌린지**: 한글 뜻과 첫 글자 힌트를 보고 철자 직접 타이핑.
3. **리스닝 딕테이션 퀴즈**: 원어민 발음을 듣고 정확한 단어를 받아적기.
4. **문맥 완성 퀴즈**: 빈칸이 뚫린 실전 예문에 알맞은 어휘 고르기.
- 연속 정답 스트릭(Streak), 콘페티(축하 효과), 아카데믹 성적표(Summa Cum Laude 배지) 제공.

### 4. 🔄 에빙하우스 망각곡선 (SRS) 복습 시스템
- 라이트너(Leitner) 5단계 박스 알고리즘 적용:
  - 1단계 (1일 주기) -> 2단계 (3일 주기) -> 3단계 (7일 주기) -> 4단계 (14일 주기) -> 5단계 (30일 주기 마스터).
- 오늘 복습하지 않으면 잊어버리는 위험 단어를 **'오늘의 복습 큐'**로 자동 추출.
- 자주 틀린 단어들만 모아 집중 복습하는 **'취약 단어 오답노트'**.

### 5. 💡 원어민 실전 표현 & 뉘앙스 Lab
- **뉘앙스 마스터**: 한국인이 가장 헷갈려하는 영단어 비교 (*Look vs See vs Watch*, *Hear vs Listen*, *Say vs Tell vs Speak vs Talk*, *Economic vs Economical*, *Empathy vs Sympathy* 등).
- **실전 콜로케이션**: *take into account*, *make an effort*, *strike a balance*, *bear in mind* 등.
- **핵심 구동사 & 이디엄**: *call it a day*, *hit the nail on the head*, *cut corners*, *bite the bullet* 등.
- **상황별 다이얼로그**: 스터디 그룹 토론, 비즈니스 미팅 실전 대화.
- 발음 듣기 및 '단어장에 추가하기' 원클릭 지원.

### 6. 📅 학습 플래너 & 캘린더 일정 편집기
- 월간/주간 캘린더 뷰에서 일자별 배정 단어 수 확인.
- 미뤄진 단어나 시험 대비 단어를 손쉽게 다른 날짜로 이동(**Reschedule**).
- **'휴식일(Rest Day)'** 지정 기능: 휴식일 지정 시 배정된 단어가 자동으로 다음 날로 연기되어 복습 주기가 밀리지 않음.
- 일일 목표 단어 수(10~100단어) 커스터마이징 및 학습 통계 그래프.

## 💻 실행 방법

### 방법 1. 원클릭 실행 (추천)
- 프로젝트 폴더 내 **`start.bat`** 파일을 더블 클릭하면 브라우저가 자동으로 열립니다.

### 방법 2. Python 로컬 웹 서버 실행
```bash
python app.py
```
- 브라우저에서 `http://localhost:8000/index.html`로 자동 연결됩니다.

### 방법 3. 브라우저에서 직접 열기
- 인터넷 브라우저(Chrome, Edge, Safari, Firefox)에서 `index.html` 파일을 더블 클릭하여 바로 여셔도 모든 기능이 100% 정상 작동합니다.
